Schalter, Licht, Spannung: Digitale Systeme arbeiten oft mit zwei unterscheidbaren Zuständen. Aber was kann man damit wirklich ausdrücken?

Leitfrage: Wofür eignen sich binäre Signale als Codierung?

01 / verstehen

Ein Signal ist noch keine Information

0 und 1 sind Zustände

Ein binäres Signal hat zwei klar unterscheidbare Zustände: zum Beispiel aus/an, dunkel/hell oder niedrige/hohe Spannung. Erst eine Vereinbarung macht daraus einen Code: etwa 0 = aus und 1 = an.

Merksatz: Daten sind eine vereinbarte Darstellung. Bedeutung entsteht erst im Kontext.

Stellenwerte im Zweiersystem

Jede Stelle steht für eine Zweierpotenz. Von rechts nach links: 1, 2, 4, 8, 16, 32, 64, 128 …

1286432168421

Beispiel: 0101 = 0·8 + 1·4 + 0·2 + 1·1 = 5.

Klicke die Bits an. Ein leuchtendes Bit zählt mit, ein dunkles nicht. Lies anschließend die Dezimalzahl ab.

03 / codieren

Aus Bits wird eine Nachricht

Eine zusätzliche Vereinbarung

Mit 8 Bits kann man viele Werte darstellen. Für Text braucht man zusätzlich eine Zuordnung wie ASCII: Ein Zeichen erhält eine Zahl, diese Zahl wird binär geschrieben.

A = 65 = 01000001

! = 33 = 00100001

Das ist nur ein Ausschnitt eines Zeichencodes. Ohne Kenntnis der Vereinbarung bleibt die Bitfolge mehrdeutig.
